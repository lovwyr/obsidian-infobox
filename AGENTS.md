# Repository Guide

Infobox is an Obsidian plugin that renders `infobox` code blocks. The user-facing syntax and examples are documented in [README.md](README.md); keep that documentation in sync when changing supported fields or behavior.

## Source And Boundaries

- Implement plugin logic in `src/main.ts`. `main.js` is generated by esbuild; do not edit it directly.
- `src/main.ts` owns code-block parsing and DOM rendering. The parser is a small YAML-like parser, not a complete YAML implementation; do not assume general YAML features work.
- Use Obsidian APIs for Markdown rendering and vault image resolution. Keep ordinary user-provided text as text rather than injecting it as HTML.
- Update `styles.css` for presentation changes and `manifest.json` only for plugin metadata or Obsidian compatibility changes.

## Workflow

- Install dependencies with `npm ci`.
- Run `npm run dev` for the esbuild watch workflow.
- Run `npm run build` before finishing; it type-checks `src/**/*.ts` and creates the production `main.js` bundle.
- There is currently no test or lint script. If behavior changes, validate with the build and add focused tests if a test framework is introduced.
